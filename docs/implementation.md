# V1 實作對照

## 重要度与資料來源

12 章重要度、150 考點的 MUST／SHOULD／OPTIONAL、前置關係與 Day 1–15 分配沿用已確認規格。公開教材附印刷頁碼、PDF頁碼、A+頁、章末題號與重要度理由；改寫練習明確標記非官方原题。

公開內容與原始講義分離。原 PDF 114 頁（印刷 4–117）的分析在 `spec/lecture-analysis.md`。章末題量 262 為重要度證據，不代表公開重製了262題原題。

V1 提供每考點兩道原創檢核，分為兩個 family。被隔離的10個考點保留可見，20題不進計分。解除隔離必須核對頁面、法源、適用年度，更新來源及題目版本，再重建教材；不要單純刪除 `issue` 就發布。

## 紀錄與狀態

IndexedDB `insurance-15day-v1` 保存主紀錄。每次變更在讀寫交易內读取最新版本，不以過期畫面快照覆蓋。BroadcastChannel 通知其他分頁重新讀取。

匯出版本為 `schemaVersion: 1.0.0`、`kind: record_export`。實際格式由 `src/importer.ts` 的 Zod 驗證，產物為 `record-export.schema.json`。它與最初規格的設計 Schema 不同：V1 把任務佇列、測驗快照和閱讀事件直接包入同一紀錄檔。舊設計的 example 是規格範例，不能直接匯入網站。未來變更格式必須另寫遷移，不接受未知版本。

匯入上限20MB，先預覽再確認，合併按識別碼去重、衝突即停止，保留目前設定。取代前保存本機備份，也提供下載舊紀錄按鈕。歷史未知題目保留但不進目前掌握度；相同版本題目重新計算對錯与概念，不信任外部檔案的 correct 值。

## 学習證據

- 同日同 family 只取第一筆；看過答案後的紀錄不作獨立證據。
- 已學：閱讀＋至少一次作答。
- 掌握：至少3次、2種 family、2個日期，最近最多5次正確率至少80%。
- 間隔複習：依正確作答日期數安排1／3／7日，答錯回1日。
- 錯題改善：最後錯誤日之後有正確作答；解決需2個較後日期、2個 family。
- 數字／期限考點同時考數值與條件，不只背孤立數字。

弱點排序：重要度 × `(錯誤+1)/(樣本+2)` × `(1+min(逾期日/間隔,1))` × `(1+min(講義對應題數,5)/5)`。最近14日最多10筆獨立證據。MUST的重要度至少0.6。

準備度為25核心掌握＋25核心加權正確率＋25正式模考證據＋15錯題修正＋10數字掌握。無證據記0，不推論能力。正式考制未確認，25分模考項暫為0；綜合練習成績另列，故暫估上限75。此限制在首頁、設定與README可見。

## 排程與模考

當日第一次開始時固定佇列，之後可接續；修改設定從未建立的下一日任務生效。Day1–11先補未學MUST，遞迴排先修；Day13補弱點與核心缺口；Day12／14／15分別1／2／1回完整練習卷，Day15不加入新課。

正式考制未知：預設40題60分鐘，實務與法規各半、優先抽較少見題型。試卷、順序、選項與到期時間保存為快照。刷新不重設計時，逾時提交，未答算錯，交卷交易具冪等性。離線關閉瀏覽器不會在背景執行程式，重新進入該卷後依既定期限結算。

一回限時卷保留額外30分鐘檢討。若設定兩回所需時間超過每日設定，介面提示增加投入。沒有足夠的來源已核題目時不捏造題目。

## PWA 與部署

React + Vite + TypeScript，hash 路由支援 GitHub Pages。`BASE_PATH`控制資源、manifest與service worker範圍；workflow自動推導儲存庫子路徑。Service worker預先快取教材與必要資產，更新採提示，進行中模考不提供立即更新按鈕。學習資料在IndexedDB不受靜態快取更新刪除。

不呼叫付費API、不上傳學習紀錄，不含帳密。來源連結需連網，其餘已快取功能可離線使用。

## 可選瀏覽器代理介面

在支援 `document.modelContext` 的瀏覽器，註冊 `read_study_summary` 與 `start_today_study_tasks`。前者僅讀摘要，後者使用同一儲存交易建立今日佇列並導覽，不代答、不標記已學。輸入僅接受空物件。一般瀏覽器未支援時略過，不影響網站。
