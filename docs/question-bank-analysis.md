## 內容理解

實務涵蓋風險與保險原理、死亡表及保費、壽險、年金、健康與傷害保險、團體與投資型商品、社會保險、招攬及核保、契約效力和理賠。法規涵蓋契約當事人與受益人、告知與解除、停效復效、保險業與業務員管理、消費者保護、稅務繼承、個資及洗錢防制。補充題另列，保留來源辨識。

每題有人工依主題整理的講義考點 ID 對照，供跳回短課，不代表原作者正式對照或逐項解答。部分稅務、期間及適用條件題另標示版本提醒。原檔未附逐題詳解，網站不虛構解析，也不把原答案宣稱為已確認的現行法規結論。

## 與 15 天計畫的關係

講義的星級、知識 A+、章末題量與重複概念仍決定 MUST／SHOULD／OPTIONAL；本題庫是補充練習，不改寫重要度。可在每日核心任務後用 10 題補充，後期依專區錯題與數字內容回看講義。專區答案符合率獨立計算，不提高正式考試準備度或替代原模考。

## 頁面與行為

首頁與導覽加入考題專區入口。專區提供四科目分區、搜尋、章節、星號、未作答、錯題及疑義篩選；可開始 10 題或依原題順序練完整篩選結果。未作答題優先，原題順序模式則保持來源排序。每次練習可暫停續作。

先選 1–4，再顯示答案欄裁圖；作答前可打開不含答案的原題圖。作答後記錄概念不懂、數字記錯、選項混淆、看錯題目、計算失誤、不確定／猜測。疑義標記排除該次計分但保留紀錄。每題最近一次有效版本紀錄決定專區統計與錯題；排除題不進錯題清單。

## 資料與維護

- `content/question-bank-source.json`：整理的原文、答案、頁碼、星號與原檔雜湊。
- `scripts/build-question-bank.py`：明確的題號到考點對照，產生 `public/data/question-bank.json`。
- `public/question-bank/`：435 張題目圖、435 張答案圖。
- `bankAttempts`：題號、題庫版本、練習 ID、選項、時間、錯因與排除標記。
- `bankRuns`：版本、題序、目前位置、開始及完成時間。

紀錄格式 1.0.0 新增可選欄位，新版接受舊備份；旧版網站未必接受含新欄位的新版備份。答案符合與否由目前同版題庫計算，不信任備份中的分數。原有學習、模考與準備度保持獨立。

執行 `npm run bank:build` 重建，再執行 `npm run check:bank` 檢查連續題號、選項標記、435 筆、870 圖、答案及映射；答案改版須同步更新題庫版本。PWA 預先快取圖文，支援 GitHub Pages 子目錄。
